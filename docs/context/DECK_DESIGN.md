状态：**构思候选 v0.1，供用户评审；尚未确认采用，未写入游戏。**

更新日期：2026-10-27（Asia/Shanghai）。本轮范围为原创角色及专属卡池构思，不包含代码、美术、平衡实测或模组发布。

## 已确认要求与设计规模

- 用户要求：有一定创新度，**有且只有三个流派**，另有组内通用卡；先构思，可以形成文档。
- 本稿将“一套卡组”解释为一个原创角色的专属原型卡池，三条路线共用同一机制，可以混搭。
- 共 **36 张不同牌**：校准流 8 张、破界流 8 张、反相流 8 张、通用卡 12 张。通用卡中含 3 种基础牌，因此常规奖励候选为 33 种。
- 初始卡组为 10 张实体牌；另给三份各 18 张的成型方向示例。它们都是设计示意，奖励分布、稀有度和实战强度尚待验证。
- 卡牌规则与数值以本文件为候选方案的唯一来源；项目当前实现状态见 [NOW.md](NOW.md)。

## 角色主题与创新点

**界尺师**是一名测量异常空间的旅人，用折尺、游标和墨线校正现实。攻击像落下刻线，防守像将裂缝重新对齐。

核心体验是：**先观察当前位置，再用出牌顺序决定这一回合要归零、越界还是反相。** 同一张“偏移 +2”的牌，在不同位置会承担不同工作。刻度高低本身没有优劣，目标由当前路线决定。

创新集中在“有方向的刻度”和“互斥的事件判定”：既能提前布置下一回合，也能在一手牌内改变路线。界面主要增加一条公开刻度，不增加专属牌堆或第二种费用。

### 基础角色候选

| 项目 | 候选值 |
| --- | --- |
| 最大生命 | 70 |
| 每回合基础能量 | 3 |
| 每回合基础抽牌 | 5 |
| 初始遗物：折尺 | 每场战斗第一次触发任一刻度事件时，抽 1 张牌。 |

以上均为设计值。初始遗物只辅助启动，不按“集齐三种事件”给予额外奖励，避免派生出第四条收集路线。

## 共同机制：刻度

刻度范围为 **−3、−2、−1、0、+1、+2、+3**，战斗开始为 0，同一战斗内跨回合保留，战斗结束清空。

带“偏移”的牌在打出时移动刻度。数字为方向和距离，例如 `+2`、`−1`；`0` 表示不移动。只有少数工具牌允许选择方向。

### 一次出牌的判定顺序

1. 检查能量、目标及出牌条件，支付费用，记录移动前刻度。
2. 应用本次偏移及已经生效的偏移修正，计算未截断的目标值。
3. 按下表从上到下判定，**一次出牌最多产生一种刻度事件**。
4. 执行当前牌的正文及“若本次发生某事件”的额外效果；条件伤害属于该牌写明的攻击段数。
5. 结算遗物、能力等对该事件的响应。响应本身不再次生成刻度事件。

| 优先级 | 事件 | 判定与最终刻度 |
| --- | --- | --- |
| 1 | **越界** | 目标值小于 −3 或大于 +3；触发一次越界，然后将刻度置为 0。 |
| 2 | **归零** | 未越界，起点非 0、终点恰为 0。 |
| 3 | **反相** | 未越界，起点与终点分别位于零点两侧，且两者均非 0。 |
| 其余 | 无事件 | 正常落到目标刻度。站在 0、到达 ±3、从 0 离开均不自动触发事件。 |

刻度事件本身没有固有伤害、格挡或回能，收益来自明确写有对应条件的牌、能力和遗物。

可读性要求：打出前预览“当前刻度 → 最终刻度”、将触发的唯一事件及条件生效后的牌面数值；`P06` 等修正也应体现在预览中。越界后的 0 应显示越界标记。

### 边界示例

| 起点与操作 | 结果 |
| --- | --- |
| +2，偏移 −2 | 到 0，归零。 |
| +2，偏移 −3 | 到 −1，反相。 |
| +2，偏移 +2 | 原目标 +4，越界后到 0；**不再触发归零**。 |
| −2，偏移 +2 | 到 0，归零。 |
| −3，偏移 −1 | 越界后到 0。 |
| 0，偏移 0 | 无事件。 |
| +3，假设偏移 −7 | 原目标 −4，按优先级只触发越界，最终到 0；此项只演示边界，不代表新增卡牌。 |

“将刻度设为 0”在起点非 0 时产生归零；“翻转刻度”将数值取相反数，起点非 0 时产生反相。它们不属于固定数值偏移，不接受“偏移量 +1”修正。

## 三个流派

| 流派 | 追求的事件与打法 | 优势 | 主要取舍 |
| --- | --- | --- | --- |
| **校准流** | 布置偏差，再精确归零；以条件高效牌和稳定补牌、格挡维持节奏。 | 单体攻防兼顾，回合之间容易保留计划。 | 要凑到恰好的差值；提前越界会错过归零收益。 |
| **破界流** | 主动推过 ±3，利用清零后的新一轮蓄力制造爆发和群伤。 | 多目标战斗与集中爆发。 | 越界后需重新蓄位；大费用牌会挤占防御空间。 |
| **反相流** | 从零点一侧直接跨到另一侧，交替使用正、负偏移牌。 | 多段攻击、连续出牌与有限回能。 | 恰好停在 0 或冲过外边界都会中断反相；需要两种方向的牌。 |

允许混搭，但混搭仍由这三类事件驱动。通用牌提供调整、基础攻防和过牌，不设计独立的第四种获益引擎。

## 初始卡组与三份成型方向

### 初始 10 张

`G01 测距 ×4 + G02 稳手 ×4 + G03 校尺 ×1 + G04 探尺 ×1`。

初始牌已经能产生三类事件：`G01 → G02` 从 0 出发会归零；`G04 → G01 → G01` 会越界；`G02 → G04` 会从 0 到 −1，再到 +1，产生反相。反相路线取得更多大幅移动牌后，才更容易持续往返。

### 三份 18 张示意牌组

这些只展示路线密度，不代表已验证的最优卡组，也不保证实际奖励流程能按此取得。

- **校准流 18 张：**G01×2、G02×2、G03×1、G04×2、G05×1、G06×1；J01×2、J02×1、J03×1、J04×1、J05×1、J06×1、J07×1、J08×1。
- **破界流 18 张：**G01×2、G02×2、G03×1、G04×2、G05×1、G06×1；P01×2、P02×1、P03×1、P04×1、P05×1、P06×1、P07×1、P08×1。
- **反相流 18 张：**G01×2、G02×2、G03×1、G04×1、G05×1、G06×1；F01×2、F02×2、F03×1、F04×1、F05×1、F06×1、F07×1、F08×1。

混搭例：校准卡可以补破界后的攻防，破界卡可以处理校准卡组的群体战，反相牌可以作为另一方向的大幅移动。越界自动清零不会触发归零能力，因此混搭需要主动安排动作。

## 三个参考回合

假设起始刻度为 0、可用能量为 3、指定牌已在手中；忽略遗物、能力、力量、敌人易伤及敌方格挡，只核对本稿规则和基础数值。

| 路线 | 顺序与刻度 | 回合基础结果 |
| --- | --- | --- |
| 校准 | G04：0→+2；J01：+2→0，归零；G05：保持 0。 | 花费 3 能量，单体伤害 7+14=21，格挡 8。 |
| 破界 | G04：0→+2；P01：原目标 +4，越界后到 0；G05：保持 0。 | 花费 3 能量，对指定目标共 7+7+6=20 伤害，对其他敌人各 6 伤害，格挡 8。 |
| 反相 | G04：0→+2；F01：+2→−1，反相；F02：−1→+2，反相。 | 花费 3 能量，单体伤害 7+5×3=22，格挡 6+5=11。 |

这些是纸面规则示例，不是游戏测试或平衡证明。反相示例用了两张专属牌，另外两例各用一张，不能据此直接比较强弱。后续需在相同奖励质量和专属牌数量下，对照反相的连击攻防、校准的持续补牌和破界的群体爆发。

## 规则边界与防止无穷循环

- 以“玩家本回合的一次实际出牌”为偏移和事件的来源；多段攻击不多次移动。未成功打出的牌不移动刻度。
- 自动重放已有出牌时，候选规则为只重复正文，不再移动刻度或生成本体系事件；条件正文沿用原出牌的判定结果。生成一张新的实体牌、再由玩家打出，则视为新的出牌。与游戏复制、重放效果的具体接入方式待核实。
- 能力响应和越界后的自动清零不触发新事件，不形成“越界→归零→再移动”的递归。
- “每回合首次”或“本回合此前”均按该玩家回合计算；新回合重置，结束战斗清除。能力不追溯生效前的事件，“首次”指能力生效后本回合第一次合格响应；同名能力后来获得新层数时，不重置本回合已用的触发次数。
- `F05` 的回能上限按同名能力整体计算；`J04`、`G03`、`J06`、`F04`、`F08` 等关键工具保留耗尽。当前不设计无成本的弃牌堆回收循环。
- `P06` 只修正下一张本角色牌的固定非零数值偏移，不影响设为 0、翻转、可选方向及无偏移牌。本稿采用最多保留一份修正、后获得的覆盖旧修正；未消耗修正在该回合结束时清除。
- `J08` 以稳定的内部“归零条件加成”标签筛选，当前对应 J01、J02、J04、J07，不依赖中文描述字符串；仅能移动仍在弃牌堆的牌。`P04` 的多份待触发效果可将格挡数值相加，共同响应下一次越界，但不增加事件次数。
- 多人候选规则：每位玩家拥有独立且公开的刻度，队友出牌不改变它。联机同步、重放去重、卡牌中途取消及死亡复活的动作顺序，均需在实现前核对实际 API。

## 升级与数值方向

- 现阶段优先确认主题、三种事件及三流派定位；所有数字均可调整。
- 攻击和防御牌可先尝试提高基础伤害或格挡；功能牌再讨论费用或保留。当前不把移除耗尽、增加触发次数或扩大偏移量作为默认升级。
- 优先检查反相连击的单位能量收益、破界群伤在多目标战斗的增长，以及同名能力叠加后的资源获取。
- 原型池规模、奖励稀有度、升级后文本、精英与首领适配、多人配合和完整一局节奏均待验证。

## 评审顺序与后续边界

1. 先确认是否采用“界尺师”主题及七格刻度。
2. 确认归零、越界、反相的互斥判定和三条路线的玩法差异。
3. 再逐张讨论卡牌数值、升级与稀有度，重点检查连击收益、群伤增长和回能上限。
4. 只有用户明确要求开始实现后，才选择相关基础库、创建运行时卡牌并执行构建、部署、加载和对局验证。

后续扩充仍只归入这三个流派或通用类别。若用户希望改变流派数量，应先明确替代本稿约束。
